# История версий

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
нумерация версий следует [Semantic Versioning](https://semver.org/lang/ru/).

## [0.2.0] — 2026-09-11

### Добавлено

- Подробные материалы для всех 100 тем: механизм работы, производственный пример, ключевое различие и связанные темы.
- Полнотекстовый поиск по расширенному содержанию карточек.
- Встроенное руководство по установке на Android и работе без подключения.
- Индикатор готовности офлайн-кэша и состояния соединения.

### Изменено

- Карточка темы стала шире и получила структурированную подачу вместо общего повторяющегося абзаца.
- Офлайн-кэш обновлён и теперь включает расширенные материалы.

## [0.1.0] — 2026-09-11

### Добавлено

- Справочник из 100 тем по MES, MOM и промышленным информационным системам.
- Девять учебных модулей, поиск и фильтрация тем.
- Отметки изученного, общий прогресс и личные заметки.
- Экзамен из десяти случайных вопросов.
- Интерактивный сценарий производственного заказа с MRP, APS, WIP, ОТК и прослеживаемостью.
- Адаптивный интерфейс для компьютеров и телефонов.
- PWA-режим, установка на Android и офлайн-кэширование.
- Автоматическое развёртывание через GitHub Pages.

## Правила нумерации

- `MAJOR` — несовместимые изменения данных, архитектуры или поведения приложения.
- `MINOR` — новые учебные модули, режимы и другие обратно совместимые возможности.
- `PATCH` — исправления ошибок, формулировок и небольшие улучшения интерфейса.
