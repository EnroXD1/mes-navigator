# История версий

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
нумерация версий следует [Semantic Versioning](https://semver.org/lang/ru/).

## [0.5.1] — 2026-09-11

### Исправлено

- Генератор QR-кодов перенесён внутрь приложения и больше не зависит от доступности внешнего CDN.
- QR-код теперь входит в обязательный офлайн-кэш и доступен после установки PWA.
- Ручная синхронизация показывает индикатор выполнения, время успешного завершения и блокирует повторные нажатия до окончания операции.

### Изменено

- В интерфейсе уточнено, что после входа через Google прогресс синхронизируется автоматически.

## [0.5.0] — 2026-09-11

### Добавлено

- Полная выгрузка прогресса в JSON с заметками, XP, экзаменами и состоянием симулятора.
- Проверяемый импорт резервной копии с безопасным объединением уже пройденных тем.
- Компактная QR-ссылка для переноса основных результатов между компьютером и Android.
- Ручной ввод ссылки или кода переноса, если QR-сканирование недоступно.
- Автоматическое распознавание входящей QR-ссылки и предварительный просмотр данных до импорта.
- Вход через Google и автоматическая синхронизация личного прогресса в Firebase Firestore.
- Объединение облачной и локальной копий без потери уже пройденных тем.
- Повторная отправка офлайн-изменений после восстановления соединения.

### Изменено

- Офлайн-кэш обновлён для хранения генератора QR-кодов и модуля Firebase после первого запуска онлайн.

## [0.4.0] — 2026-09-11

### Добавлено

- Поисковый словарь сокращений из производственного, инженерного, ИТ-, правового и экономического контекста.
- Для каждой аббревиатуры: полная форма, русский смысл, назначение, место в общей системе и простой пример с производства.
- Автоматическая подборка релевантных сокращений в карточке каждой темы и на теоретическом шаге урока.
- Переходы из словаря к связанным темам и поиск тем по содержащимся в них аббревиатурам.
- Инструмент поиска расшифровок через интерфейс приложения.

### Изменено

- Офлайн-кэш и описание PWA обновлены для работы словаря без интернета.

## [0.3.0] — 2026-09-11

### Добавлено

- Последовательный учебный маршрут: доступна первая непройденная тема, следующие открываются после практики.
- Короткий урок из четырёх шагов для каждой из 100 тем: теория, схема, распознавание понятия и производственный пример.
- Сто уникальных схем «вход → механизм → результат».
- Очки опыта, серия учебных дней и награда за урок с учётом ошибок.
- Визуальный маршрут текущего модуля со статусами пройденных, доступной и заблокированных тем.
- Возможность повторять пройденные уроки без сброса прогресса.

### Изменено

- Ручная кнопка «Отметить изученной» заменена обязательным прохождением заданий.
- Инструменты приложения больше не позволяют засчитывать тему в обход урока.
- Офлайн-кэш обновлён для хранения схем и логики учебных уроков.

## [0.2.0] — 2026-09-11

### Добавлено

- Подробные материалы для всех 100 тем: механизм работы, производственный пример, ключевое различие и связанные темы.
- Полнотекстовый поиск по расширенному содержанию карточек.
- Встроенное руководство по установке на Android и работе без подключения.
- Индикатор готовности офлайн-кэша и состояния соединения.

### Изменено

- Карточка темы стала шире и получила структурированную подачу вместо общего повторяющегося абзаца.
- Офлайн-кэш обновлён и теперь включает расширенные материалы.

## [0.1.0] — 2026-09-11

### Добавлено

- Справочник из 100 тем по MES, MOM и промышленным информационным системам.
- Девять учебных модулей, поиск и фильтрация тем.
- Отметки изученного, общий прогресс и личные заметки.
- Экзамен из десяти случайных вопросов.
- Интерактивный сценарий производственного заказа с MRP, APS, WIP, ОТК и прослеживаемостью.
- Адаптивный интерфейс для компьютеров и телефонов.
- PWA-режим, установка на Android и офлайн-кэширование.
- Автоматическое развёртывание через GitHub Pages.

## Правила нумерации

- `MAJOR` — несовместимые изменения данных, архитектуры или поведения приложения.
- `MINOR` — новые учебные модули, режимы и другие обратно совместимые возможности.
- `PATCH` — исправления ошибок, формулировок и небольшие улучшения интерфейса.
