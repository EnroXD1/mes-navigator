# Цех знаний — MES/MOM

Интерактивный учебный тренажёр по промышленным информационным системам.

## Возможности

- 100 подробных тем с практическими примерами и ключевыми различиями;
- последовательный трек ProductionDatabase 96 + ProductionPlanner: 25 модулей, 250 базовых и 200 углублённых вопросов;
- мини-практики, очередь повторения и связь проектных модулей с базовыми темами;
- отдельный словарь промышленных и ИТ-аббревиатур с полной расшифровкой, ролью и простыми примерами;
- связанные с темой сокращения прямо в карточке и внутри урока;
- полный экспорт и безопасное объединение прогресса из JSON-файла;
- быстрый перенос выполненных тем между устройствами по QR-ссылке;
- автоматическая синхронизация через Firebase после входа в Google-аккаунт;
- ИИ-наставник с подсказками по текущей теме или модулю PD96 через бесплатный маршрут OpenRouter;
- последовательный маршрут из коротких уроков;
- отдельная схема и два задания для каждой темы;
- очки опыта, серия учебных дней и блокировка следующих уроков до прохождения текущего;
- личные заметки;
- экзамен по определениям;
- симулятор производственного заказа;
- установка на Android как PWA;
- работа без подключения после первого открытия.

## ИИ-наставник

1. Откройте тему или модуль PD96 и нажмите «Спросить ИИ о теме» / «Разобрать с ИИ». Кнопка «ИИ-наставник» в шапке открывает подсказки по следующей теме.
2. Нажмите «Войти через OpenRouter» и авторизуйтесь там либо вставьте свой существующий API-ключ OpenRouter. По правилам OpenRouter сервис доступен с 18 лет. Регистрация и бесплатный маршрут моделей не требуют покупки кредитов, но действуют суточные лимиты и ограничения доступности.
3. Сформулируйте вопрос и нажмите «Отправить». Модель получит текст вашего вопроса, краткий контекст выбранной темы и недавнюю переписку. Прогресс, заметки, Google-аккаунт и Firebase-данные не передаются.

Приложение всегда выбирает `openrouter/free`, поэтому не вызывает платные модели. Полученный ключ хранится в `sessionStorage` текущей вкладки и удаляется при закрытии вкладки или нажатии «Отключить». Если вход через OpenRouter создаёт ключ, само отключение в приложении не удаляет его из аккаунта OpenRouter — при необходимости удалите его на [странице ключей](https://openrouter.ai/settings/keys). Не вводите в чат секреты или персональные данные. ИИ-наставник работает только онлайн; сам курс доступен офлайн.

Ответы отображаются как Markdown: выделение, списки, ссылки, блоки кода и таблицы. Широкие таблицы можно прокручивать по горизонтали на телефоне. Сырой HTML и изображения из ответа модели не отображаются как элементы страницы.

## Локальный запуск

Приложение является статическим. Для полноценной проверки PWA откройте папку
`dist` через любой локальный HTTP-сервер.

## Android и офлайн-режим

1. Откройте `https://enroxd1.github.io/mes-navigator/` в Chrome при подключённом интернете.
2. Нажмите «Установка и офлайн» в приложении либо выберите в меню Chrome пункт
   «Установить приложение» / «Добавить на главный экран».
3. После установки один раз запустите приложение онлайн и дождитесь сообщения,
   что офлайн-кэш готов.
4. Затем приложение можно открывать с главного экрана без подключения к интернету.

Прогресс сначала сохраняется локально и остаётся доступным без сети. После входа
через Google приложение объединяет локальную и облачную копии Firebase и отправляет
последующие изменения автоматически при наличии соединения.

## Облачная синхронизация

1. Откройте «Синхронизация» и войдите через Google.
2. Повторите вход с тем же аккаунтом на другом устройстве.
3. При подключении приложение объединит выполненные темы, сохранит максимальные XP
   и лучший результат экзамена, а также прогресс трека PD96, затем продолжит синхронизацию автоматически.
4. Во время работы без сети изменения остаются на устройстве и отправляются после
   восстановления соединения.

Облачная запись хранится отдельно для каждого Firebase UID. Резервный JSON-файл и
QR-ссылка остаются альтернативой, если вход или соединение недоступны.

## Перенос прогресса

- JSON-копия переносит пройденные темы, XP, серию, результаты экзаменов, заметки и состояние симулятора.
- QR-ссылка предназначена для быстрого переноса основных результатов и прогресса PD96; заметки в неё не включаются.
- Импорт объединяет выполненные темы и не удаляет уже существующий прогресс на принимающем устройстве.
